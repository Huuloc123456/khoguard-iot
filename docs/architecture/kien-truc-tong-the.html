Kiến trúc tổng thể KhoGuard

  • Luồng dữ liệu: ESP32 trong Wokwi và các SIM-* publish telemetry/events/status QoS1 lên Mosquitto; backend subscribe, kiểm hợp đồng (Ajv) rồi ghi MySQL trong một transaction, sau đó đẩy snapshot qua WebSocket mỗi giây.
  • Điều khiển: operator gửi lệnh qua POST /api/doors/D07|D08/commands; backend publish xuống commands/ESP-C01, ESP-C01 tự quyết định theo quy tắc an toàn và trả ack. Chi tiết ở sơ đồ luồng lệnh cửa.
  • Bảo mật: mọi cổng chỉ nghe 127.0.0.1; ESP32 tới máy qua host.wokwi.internal của gateway. MQTT/TLS bằng CA demo, mỗi thiết bị một tài khoản và ACL mặc định từ chối; dashboard dùng cookie kg_session HttpOnly. Bí mật chỉ nằm trong .local/.
  • Cổng 9080 của gateway Wokwi nghe trên mọi interface (hành vi upstream); firmware không có HTTP server nên không mở firewall cho cổng này.
