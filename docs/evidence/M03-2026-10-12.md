## Những lần chưa đạt và giới hạn

- Gateway tích hợp gửi telemetry nhưng khi broker mất, UART/heartbeat dừng, observer timeout 45 giây sau broker restore. Gặp với Arduino 3.3.12 và 2.0.17; không kết luận đổi Arduino core sửa reconnect.
- Reload Window rồi Start Simulator qua gateway native chạy được và reconnect đạt. Chưa xác minh nguyên nhân nội bộ Go/WASM gateway; không coi suy đoán là kết quả debug.
- Native gateway 9011 bind loopback nhưng upstream forward 9080 trên mọi interface; --forward= không tắt nó. Không có HTTP server trong probe. Dừng gateway sau demo, giới hạn ingress trước khi mở HTTP trong simulator.
- Port probe cũ bind Any gây hộp thoại PowerShell Firewall. Người dùng yêu cầu hoàn tác Allow nhầm; quyền thường không đủ, UAC lần đầu bị Cancel, lần hai cho phép chạy/gỡ đúng hai Allow Public rồi Cancel Firewall. Kiểm tra lại thấy Block/Public. Startscript cuối chỉ thử bind loopback.
- Không chạy MQTTX GUI, Last Will riêng hoặc mất WiFi riêng; chưa thử lỗi DHT bằng tháo dây. Null/range/freshness có trong code, chưa phải kiểm định cảm biến thật.
- Chưa TLS, NTP, command execution, safety controller hoặc ingest vào MySQL. Dashboard vẫn là demo frontend.
