# M16 — bằng chứng 13/10/2026

Trạng thái: **đạt trong sandbox với ESP-C01 giả lập bằng Node; bốn kịch bản và T08 đạt trên firmware Wokwi thật ngày 13/10/2026** ([nghiệm thu Wokwi](WOKWI-2026-10-13.md)). Chưa đánh dấu M16 hoàn tất vì T17, T24, T26 mới đạt một phần. Mọi số liệu cảm biến là mô phỏng.

## Đã làm

- `scripts/sim-lib.mjs`: PRNG có seed (`mulberry32`), đồng hồ ảo, `SimDevice` (mỗi thiết bị một tài khoản MQTT, Last Will, envelope đúng hợp đồng) và `FakeEdge` thay ESP-C01 khi không chạy Wokwi. FakeEdge làm lại dạng rút gọn quy tắc đóng/mở M09: OCCUPIED, PRESENCE_DETECTED, BEAM_BLOCKED, PANIC_ACTIVE, INTERLOCK_ACTIVE, REVISION_MISMATCH, COMMAND_EXPIRED.
- `npm run demo:warehouse -- --seed=17 [--seconds=N] [--with-fake-esp]`: 4 khu, 12 cửa từ SIM-A01, SIM-B01, SIM-C02, SIM-D01 (và ESP-C01 giả nếu chọn), mỗi 2 giây.
- `npm run demo:scenarios -- --scenario=all|1..4`: bốn kịch bản Agent.md §11 đi qua MQTT → backend → MySQL → API.
- `npm run load:test -- --nodes=50 --seconds=60 --burst=500`: tự bật backend, đo ingest (theo `received_at` trong DB) và publish → WebSocket (marker nhiệt độ), RSS backend.
- `npm run verify:all [-- --skip=a,b]`: chạy mọi kiểm tra theo thứ tự phụ thuộc, ghi `.local/verify-all.json`.
